# 🎯 Smart Resume & Job Matcher

A clean, lightweight web utility built with *Python* and *Streamlit* that evaluates resume alignment against real Job Descriptions (JDs).

## ✨ Features
- *PDF Resume Extraction*: Upload resumes directly in .pdf format.
- *Keyword Matching Engine*: Analyzes overlap between job role requirements and candidate profiles.
- *Gap Analysis*: Highlights missing keywords to help tailor resumes before applying.

## 🛠️ Tech Stack
- *Language*: Python
- *UI Framework*: Streamlit
- *PDF Parser*: pypdf
